## 🎯 What CampusHUB Does
CampusHUB is a minimalist, responsive web application tailored for Gen Z university students in Phnom Penh looking for the ideal place to study, finish assignments, or collaborate on group projects.

### Core Features:
- 🗺️ **Zero-API Interactive Map**: Instant Leaflet + OpenStreetMap integration showing nearby cafes and campus landmarks without external API key dependencies.
- ⚡ **Verified Wi-Fi & Power Outlets**: Accurate download speed metrics (Mbps) and outlet density ratings (plenty vs. wall outlets).
- 📍 **Campus Proximity Calculator**: Real-time walking and scooter travel times from top Phnom Penh universities.
- 💵 **Student Budget Filters**: Filter by coffee prices (under $2), noise levels (quiet focus vs. lively), and free guarded moto parking.
- 🌙 **True OLED Dark & Light Mode**: Ultra-deep pitch black for night study sessions and warm soft linen for daylight reading.
- 🇰🇭 **Bilingual Support**: Instant toggle between English and Khmer (ភាសាខ្មែរ).
- 📱 **1-Tap Social Actions**: Direct navigation links to Google Maps and quick study group sharing via Telegram.

## 🚀 Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/pichpisethheng-cloud/CampusHUB.git
   cd CampusHUB
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
